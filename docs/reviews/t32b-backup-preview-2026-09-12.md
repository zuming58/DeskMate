# T32B：本地备份与校验预览

本轮属于第一包的增量，不代表“备份与恢复”全部交付。

## 已开放

入口：设备与诊断 → 数据与备份。

- 创建版本化 `.deskmate-backup.json` 文件，包含输入/陪伴设置、词库、提示词工作区（个人提示词、场景、排序和绑定）、主库语音历史、本地记忆、摘要、候选审核状态与来源字段。
- 原始录音默认不勾选；勾选后包含受管录音（含仍保留的未引用录音）。总包限制 256 MB，超限明确失败，可取消录音后重试。
- 不导出账号密钥、设备路径或已登记应用的启动路径。正文仍是私人数据，不适合当诊断包公开分享。
- 导出在独立 worker 内读取各库一致快照、校验源内容、重建隔离验证库、校验文件后发布，不锁语音状态机。已有待写历史必须先完成。各库快照不是跨库同一瞬间事务；之后新增内容留待下次备份。
- 原生文件选择；渲染端只收到状态和数量，不接触文件路径。执行中禁止重复点击，失败后可重试。
- “校验备份并预览”显示日期和条目数量，不修改主库、不排队恢复、不重启、不写硬件、不提交中枢。隔离校验目录在结束后清除，只包含本次校验临时副本。

## 已有测试基础，但未在产品启用

离线引擎从可信产品 schema 重建数据库，保存恢复前快照，按白名单替换文件。已测试部分写入后异常回滚、子进程真正退出后下次入口回滚、快照阶段磁盘不足保留原文件、恶意目标/字段拒绝、原始日期/来源/审核状态保留。

这不等于运行中软件已经可以安全恢复。因此没有对外恢复 IPC，也没有可以误点的覆盖按钮。以下完成前不可启用：

1. 录音、转写、整理、记忆生成/同步、待保存队列的统一维护锁及确认时二次检查。
2. 启动前执行离线作业，失败回滚或停止启动；React 挂载正常副作用前完成配置交接。
3. 应用路径和凭据重新确认、后台唤醒/调度暂停、旧日记按日期防重发的实际消费逻辑。引擎写入的 hold 标记目前不能冒充已生效。
4. 完整覆盖其余可迁移软件设置、恢复入口和上次有效快照的用户可见操作。

7/20 天自动清理、场景归档管理和全界面收尾仍在后续包。未清理用户的真实录音、文字、迁移源或 KnowledgeOS Raw。
