# T33：经确认的本地自动清理

## 交付结果

DeskMate 现在把原始录音和原始文字纳入同一个可恢复清理流程：录音默认保留 7 天，文字默认保留 20 天，两项均可在 1–365 天内调整。新安装和升级默认不删除；用户必须先看到本次精确数量及保留原因，再点击“确认本次并启用”。修改任一期限会撤销旧授权。

达到天数并不自动等于可删。录音必须有明确成功转写、可靠日期且无未完成关联；与记忆关联的原文必须已有完成的日终总结。启用 KnowledgeOS 日终同步后，还必须等同一天的 `work` 与 `personal` 两份日记均被受理。日期未知、转写失败、总结缺失、同步未完成、关联异常和孤立录音均保留并显示原因。

## 数据边界

- 清理主历史 SQLite、受管录音文件、记忆原始回合和对应原始事务；不会清理小时/日终摘要、日记、候选、已确认长期记忆或 KnowledgeOS Raw。
- 渲染端旧 localStorage/IndexedDB 副本只按同一批精确 ID 清理；保留文字若只失去到期录音，会标记录音已不可用。
- 手动导出的 `.deskmate-backup.json` 不在扫描范围内。
- 清理前把精确数据库行和录音复制到内部恢复任务；数据库、文件、浏览器副本和完成确认分阶段记录。成功任务的内部恢复副本保留 7 天后才由受管目录清理。
- 预览十分钟过期；确认前重新校验候选指纹。预览后新增的记录不会被加入已确认删除集合。

## 运行与界面

入口：记忆管理 → 本地自动清理。页面显示启用状态、7/20 天规则、上次完成时间、待完成任务、清理数量与具体保留原因。启用后每天本地日历最多自动检查一次；录音、连续对话、写历史、备份、摘要或 KnowledgeOS 同步忙碌时跳过，后续重试。也可手动“立即检查”。

诊断只导出期限、数量、启用/待处理状态和白名单原因码，不导出文字、录音、路径或凭据。

## 验证与限制

- 完整自动测试：635/635；T33 专项后来扩展为 10 项，覆盖旧策略迁移、非破坏预览、确认清理、7/20 天边界、KnowledgeOS 双回执门槛、并发新增、真实子进程退出后的任务恢复、损坏录音阻断、浏览器精确 ID 清理和脱敏诊断。
- 隔离 Electron UI 探针覆盖 7/20 天显示、预览数量、保留原因和确认按钮；不使用用户资料、麦克风、网络或硬件。
- 独立候选包已通过原生桥、渲染构建、Electron 目录打包和包内资源逐字节校验。构建标识为 `t33-consent-retention`；`DeskMate.exe` SHA256 为 `9FCD6F2988B2B94D73C5EC66ED4E109667F68C20897C36BF1C889B99A07595F8`，`app.asar` SHA256 为 `1368012563E4D780C0173667D5901F1DA959113FB163976FB28652165E80E929`。
