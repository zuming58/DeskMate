## Xiaozhi implementation

- Added a Host-testable seven-state scene selector. `working` explicitly falls
  back from `focused` to `neutral` when unsupported; `angry` is never selected
  by the automatic map.
- Added one synchronized display owner with a four-entry bounded queue. Link
  enqueues states and ACKs only accepted or duplicate state submissions.
- DISPLAY is advertised dynamically only after display initialization. Init
  failure keeps it absent; render/task failure keeps it implemented but removes
  it from enabled and sets the existing status fault bit. Link stays usable.
- Disconnect and controller boot-epoch changes clear cached requests and stale
  display work, settle desired state to idle and do not replay the old state.
- TTL remains owned by EasyInput as frozen. Xiaozhi renders idle only when it
  receives that new live Link transition; no new TTL wire field was invented.
- Added the only OLED writer: SSD1306 128 x 64, I2C0, GPIO41/GPIO42, address
  `0x3c`, 400 kHz, internal pull-ups and X/Y mirroring. Scenes are generated by
  new one-bit procedural drawing code.
- Audio, microphone, amplifier, speaker, I2S, servo, LEDC, PWM and idle motion
  remain uninitialized and unused.
