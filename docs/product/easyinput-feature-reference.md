# EasyInput feature reference

`design/references/easyinput-app/` 保存脱敏后的界面参考图，只用于理解功能和状态反馈，不复制其品牌或视觉实现。包含用户历史正文、账号、网络地址或录屏的素材没有迁移。

已观察功能：

- 概览统计、语音待机/录音声波、历史、词库和替换规则。
- 八个按键及旋钮的高层动作映射和同步。
- 电脑/键盘麦克风优先级、2.4 GHz Wi-Fi、开机音效和编程助手灯效。
- 快捷键、输入策略、文本整理、标点、悬浮窗、主题与语言。
- 按键动作包括语音输入、语音编辑、全选、复制、粘贴、撤销、禁用、快捷键和固定文字。

DeskMate 的原则：保留必要能力，但用自己的信息架构、视觉系统、协议层和安全边界重新实现。
