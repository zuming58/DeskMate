# T57 reminder purpose extraction and deletion

Status: `T57_REMINDER_PURPOSE_DELETE_V1_FROZEN`

The T56 local parser persisted any nonempty leftover title before semantic extraction could run. Mixed conversation/purpose replies therefore included unrelated chat and request wrappers. T57 defers creation on the asynchronous production route. Simple unambiguous purposes remain local; mixed clauses or leftover request language use one bounded, reminder-only title extraction (6-second timeout). The model receives the current utterance and proposed purpose, not the full history, credentials or tools. It cannot choose reminder/event timestamps. Extracted title must be grounded in the original purpose with bounded colloquial normalization; negation and numeric quantities cannot be dropped. Failures keep a short purpose clarification with validated timestamps, never silently save the raw mixed chat. Cancellation/newer turn/expiry invalidates in-flight results. Existing contextual time proposals retain their confirmation rules. No continuous API calls, no changes to 500 ms endpointing or ordinary dictation.

Workbench reminder rows have Delete -> selected-title confirmation -> main-owned narrow IPC -> validated atomic store removal -> scheduler rearm and snapshot event. Cancellation does nothing. Failed saves remain visible and retryable. Deletion removes only the selected reminder, not conversation history or KnowledgeOS memory. A delivering reminder cannot be deleted until audio delivery ends; pending/failed/notified/important records can be removed. Late delivery callbacks cannot resurrect a missing row. Existing internal previous snapshot behavior is unchanged; this is not secure erasure of backups. No automatic deletion or title rewriting of the user's existing records.

Verify mixed chat before/after reminder intent, purpose-only follow-up, title grounding, unchanged times, unavailable/invalid model, cancellation/expiry, deletion persistence/failure/restart, timer rearm, in-flight protection and real UI confirm/cancel/retry at 1440x1024 and 960x680. Synthetic model results are not live model-quality acceptance.
