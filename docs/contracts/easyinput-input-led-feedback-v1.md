# EasyInput input LED feedback v1

- 状态：`INPUT_LED_V1_FROZEN`
- 冻结日期：2026-08-27
- 适用范围：DeskMate EasyInput V2.0 固件内部的实体输入可见反馈
- 板级来源：5 颗串联 WS2812（GRB）使用 GPIO12；GPIO8 是 LED、麦克风和扬声器共享的高有效电源域

## Product behavior

空闲时 5 颗灯保持全黑。只有经过 T03 防抖/正交解码确认的语义输入事件可以触发灯效；GPIO ISR、原始抖动、HID 重试和 USB 生命周期事件不得直接触发灯效。

| 输入 | 颜色 RGB | 效果 | 总时长 | 帧间隔 |
| --- | --- | --- | ---: | ---: |
| S1 | `28,0,0` | 5 灯波纹 | 140 ms | 35 ms |
| S2 | `28,10,0` | 5 灯波纹 | 140 ms | 35 ms |
| S3 | `26,20,0` | 5 灯波纹 | 140 ms | 35 ms |
| S4 | `0,28,0` | 5 灯波纹 | 140 ms | 35 ms |
| S5 | `0,22,22` | 5 灯波纹 | 140 ms | 35 ms |
| S6 | `0,0,28` | 5 灯波纹 | 140 ms | 35 ms |
| S7 | `18,0,28` | 5 灯波纹 | 140 ms | 35 ms |
| S8 | `22,22,22` | 5 灯波纹 | 140 ms | 35 ms |
| 旋钮左转 | `0,0,28` | 向左流动 | 160 ms | 40 ms |
| 旋钮右转 | `0,22,22` | 向右流动 | 160 ms | 40 ms |
| 旋钮按下 | `22,18,10` | 确认脉冲 | 300 ms | 60 ms |

- 每次稳定按下只触发一次。实体键保持按住时不得持续重触发；松开不产生第二个灯效。
- S1/S3 的 held PTT 语义和 S2/S4/S5～S8 的 atomic tap 语义不因灯效改变。
- 旋钮每个已确认 detent 可更新方向反馈；非法 Gray-code 跳变不显示。
- 新输入可以替换尚未完成的旧灯效；允许合并或丢弃过时灯帧，但不得丢弃、延迟或重排 HID 输入。
- T04 不加入开机彩虹、连接状态、Agent 状态、配置状态或独立 GPIO42 状态灯语义。
- 当前样机 S8 的 GPIO48 输入电路已知损坏：没有稳定输入事件就没有灯效。Host 测试仍覆盖 S8，健康实板仍须验收。

## Shared-power safety

- GPIO8 只能由一个 `PeripheralPowerController` 写入；LED 组件不得直接写 GPIO8。
- 冷启动先预装 GPIO8 低，再把 GPIO9/10/12/13/14/15 命令输出预装为低，并保持 GPIO11 禁用/浮空；随后才把 GPIO8 配为输出并拉高。
- T04 采用固定 Maker 同板参考的 50 ms 阻塞稳定等待作为当前实现策略，并必须在真机验收中验证。它不是通用于所有硬件修订的永久电气常数。
- 设备处于 Awake 时由共享电源控制器保持电源域开启；按键灯效只发送 RGB/黑帧，绝不按键级开关 GPIO8。
- 黑帧只表示灯灭，不表示共享电源域关闭。T04 不实现深睡、电源关闭、麦克风或扬声器初始化。
- LED 初始化、队列或 RMT 传输失败必须 fail-soft：记录有界脱敏计数并让 T03 输入/HID 继续工作。

## Ownership and timing

- T03 的输入状态机是唯一语义输入来源；T04 不建立第二套按键扫描、防抖、旋钮解码或 HID 状态机。
- 灯效必须在输入/HID 事件已经入队后异步处理，不在 GPIO ISR 或输入热路径中执行 RMT 发送、等待或日志。
- 5 像素使用 GRB 顺序。RMT 传输必须有界；完成等待或错误不得阻塞后续输入处理。
- 灯效队列必须有界并采用“最新反馈优先”或等价的可证明策略。溢出只增加 `led_feedback_dropped`，不得触发输入恢复、全释放或 USB 重连。
- 诊断可包含灯效丢弃、初始化失败和发送失败计数，不得包含按键正文、录音、识别文本、设备路径或设备身份。

## Change control

亮度、颜色、动画、持续时间、输入事件来源、GPIO8 时序或 GPIO12/RMT 驱动的改变都属于本合同变更。T04 只能实现本切片；后续 Agent/连接状态灯效和音频共享电源扩展必须通过新的任务卡与回归门。
