## 下载前先确认

- 硬件：EasyInput V2.0（板型别名 v2，PCB 丝印 AI Keyboard V2.1），ESP32-S3R8、16 MB Flash；不适用于其他型号。
- 配套软件：DeskMate Windows 0.1.7。本包采用既有 T43A 固件，固件版本 `57d30d3`，不是把桌面软件版本冒充固件版本。
- 这是 **app-only 应用升级包**，不是空白板首次安装包，也不是恢复整机备份。已有分区必须与下表逐项一致，现有启动程序须兼容；分区未知、启用安全启动/Flash 加密或型号不符时，停止，不要尝试强刷。
- 不需要小智云台。在 DeskMate 中保持小智扩展关闭即可；实体云台功能不可用不等于 EasyInput 输入故障。

## 升级注意事项

1. 先保存自己设备的配置和恢复资料，确认板型、启动程序及上述分区。不会判断时，把板型和原固件版本提供给作者确认，不能仅凭“也是 ESP32-S3”刷入。
2. 当前板进入下载模式：**保持开机，短按一次 BOOT 并松开**。不需要按住 BOOT 再上电，板上没有供用户操作的独立 RESET 键。
3. 使用可信烧录工具并核对目标设备，只把本包应用写到 **0x10000**。应用数据末地址为 **0xE6F0F**，扇区擦除范围 **0x10000–0xE6FFF**。不要选择全片擦除，不写 bootloader、分区表、NVS、PHY 或声音分区，不写 eFuse。本包不附会自动连接设备或擦除设备的脚本。
4. 写入并校验成功后，用板上开关关机再开机，退出下载模式，不再次按 BOOT。
5. 启动 DeskMate，检查八个按键、旋钮、灯效与语音输入；板载网络音频须使用自己的配置。已有按键映射予以保留，不保证出厂映射与作者相同。
