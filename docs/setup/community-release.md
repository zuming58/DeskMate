# DeskMate 社区版：安装、隐私与许可

## 获取软件

官方下载页：<https://github.com/zuming58/DeskMate/releases/latest>。

在 Assets（资源）中下载 `DeskMate-<版本>-setup.exe`，不要把 GitHub 自动附带的 `Source code.zip` 当作安装包。Windows 社区版目前面向 Windows 10/11 x64；Mac 版尚未完成适配与真机验收，没有可承诺功能完整的正式安装包。

安装包没有代码签名证书，Windows 可能显示未知发布者提示。请核对来源和同一 Release 中的 SHA-256，不要关闭杀毒软件来安装来历不明的副本。升级前从托盘完整退出旧版，再运行新版安装器；保留同一安装路径，现有设置与记录独立保存在系统用户数据目录。

## 第一次启动

1. 称呼使用“关于我”中保存的名字；没有个人资料时默认为“小明”，年龄、职业等留空。陪伴名为“小岚”，可以在 AI 陪伴设置中修改。
2. 到设备与诊断中选择自己的麦克风、扬声器，配置自己的语音与文本模型服务。
3. 软件免费使用不代表云 API 免费。AI 语音、文字整理、图片生成等费用由使用者自己的服务账户承担。
4. 没有 EasyInput/小智硬件也可使用电脑音频和软件页面；硬件相关功能仅在实际连接、能力与安全条件满足时可用。安装器不会烧录固件。
5. KnowledgeOS 是可选的独立服务，不随此安装包安装且默认关闭。“记忆管理”顶部可开关；关闭后仅本地存储，长期记忆和摘要没有自动到期删除。只有显式启用并配置自己的服务后才同步；本地保存不代表已写入云端。开启前会提醒可能包含历史待同步日记。
6. 小智云台扩展默认关闭；有硬件的使用者可在“设备与诊断 → 设备连接”手动开启。已有安装保存的开关与个人资料继续保留。

## 数据边界

- 安装包只包含程序、必要运行库、模型和内置演示资源，不包含作者的用户配置、API 密钥、聊天记录、长期记忆库、提醒、录音或备份。
- 凭据在本机主进程加密保存，不复制作者的配置到新用户机器。自动记忆整理默认关闭，开启前说明模型费用和内容外发范围。
- 普通后台本地唤醒识别不调用云端 API；前台语音会话、启用的摘要/自动整理、图片生成与到点语音播报等可能调用用户配置的服务。
- 向社区报告问题请使用软件的脱敏诊断；不要上传整个用户数据目录、数据库、原始日志或密钥。
- Git 历史是公开资料；提交前扫描不能证明不存在所有形式的敏感信息。发现疑似泄漏应私下联系作者，真实密钥泄漏须撤销并更换，不能只删当前文件。

## macOS 边界

当前输入桥使用 .NET Windows Forms、Raw Input、user32 与 PowerShell。Mac 版需要独立的键盘/目标窗口适配、麦克风及辅助功能权限说明、原生依赖的架构验证，并在 macOS 上构建、测试、签名与公证。只把扩展名改为 DMG 或生成一个能打开的窗口，不能证明语音输入和硬件功能可用。完成前不把 Windows 包标记为 Mac 兼容版。
