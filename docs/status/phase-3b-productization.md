# Phase 3B：语音输入产品化与智能整理状态

> 本文是历史阶段记录。当前跨电脑迁移和代码地图以 [standalone handoff](../handoffs/desktop-handoff-2026-08-23.md) 为准。

> 2026-08-29 后续说明：百炼仍是已验证默认文本模型；T07D 新增了 Electron 主进程加密的 OpenAI 兼容文本模型配置，可让智能整理与 KEY3 语音编辑共同切换到 DeepSeek 等兼容服务。实时陪伴语音是独立配置面，尚未启用。

更新时间：2026-08-22

## 已完成

- Windows 正式图标：应用窗口、任务栏、可执行文件和系统托盘统一使用深灰底青蓝机器人脸；ICO 包含 16/20/24/32/40/48/64/256px，并带 PNG 备用资源。
- 托盘行为：单击打开主界面，右键可开始/停止语音输入、打开设置与诊断或退出；关闭主窗口后继续驻留托盘。
- 文字整理：复用 Windows 加密保存的百炼 API Key，在 Electron 主进程调用 `qwen3.7-flash`；渲染进程无法读取密钥。
- 三种模式：原样输出只执行确定性替换；智能整理清理口头语、重复、标点和明显识别错误；自定义整理在同一安全约束下追加用户要求。
- 安全回退：空结果、非法 JSON、网络错误、15 秒超时或配置错误均保留并输出原始转写；`Esc` 可取消整理且不会丢失历史。
- 状态机：增加 `organizing`，完整链路为 `recording → transcribing → organizing → outputting → completed/error`。
- 历史 schema v5：同时保存 `rawText` 和最终 `text`，记录模式、模型、耗时、成功/回退状态；旧历史自动令 `rawText = text`。
- 历史页：可切换查看原始转写与整理结果，分别复制；回退记录明确显示“已保留原文”。
- 首次真机触发竞态：F22 事件的明确 `start/stop` 阶段现在直接驱动录音器，避免首次从其他页面进入语音页时发生双开始。

## 验证结果

- `npm test`：50 项全部通过。
- Web/Sites 构建：通过。
- Windows x64 目录包：通过，输入桥和图标资源均随包生成。
- 打包版冒烟测试：Mock 录音 → 转写 → 历史 → 剪贴板闭环通过。
- 本机真实百炼整理：`qwen3.7-flash` 成功，样例耗时约 690ms；测试报告不包含密钥或文本正文。
- EXE 关联图标与随包托盘资源均非空，16px 图标可辨认。

## 当前边界

- 默认仍为“原样输出”；只有用户主动选择智能或自定义模式才调用文字模型。
- 本阶段继续使用电脑麦克风，不宣称已接入板载 Wi-Fi 麦克风。
- 不修改固件，不控制未来桌宠屏幕、灯效、舵机或传感器。
- 当前电脑旧 `release/win-unpacked/DeskMate.exe` 曾被 360/资源管理器占用，因此本轮成品验证使用隔离目录 `release-phase3b-verify/`；该目录是本地产物，不提交 Git。其他电脑正常运行 `npm run build:desktop` 即可生成标准 `release/`。
