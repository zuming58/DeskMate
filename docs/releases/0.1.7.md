# DeskMate 0.1.7 · Windows 社区试用版

DeskMate 把语音输入、桌面 AI 陪伴、提示词、风格映像、个人提醒和本地记忆放在一个 Windows 工作台里。无需 EasyInput 或小智硬件，也可以使用电脑麦克风和软件界面。

## 下载与安装

- 选择 `DeskMate-0.1.7-setup.exe`，适用于 Windows 10/11 x64。
- 安装后可通过桌面 DeskMate 图标启动；升级保留原设置和本地记录。首次使用请自行配置语音、文本和图片服务。
- 此安装器未进行商业代码签名，Windows 可能提示未知发布者。只从本项目 Releases 下载，并可与 `SHA256SUMS.txt` 核对文件哈希。
- 本次没有发布 macOS 安装器。Mac 的原生输入桥、权限与实际运行仍需适配和验证，不能以 Windows 构建结果代替。

## 默认设置

- 新用户称呼默认为“小明”；在 AI 陪伴的个人资料中填写后，按你的资料称呼，不包含开发者的个人档案。
- 小智云台扩展默认关闭；拥有对应硬件时再开启。
- KnowledgeOS 默认关闭。这是可选的外部软件，不是使用 DeskMate 记忆功能的前提。
- 每日摘要与长期记忆保存到本地，不按天数自动清理；原始文字和录音仍适用单独的保留策略。主动删除或卸载时自行删除数据目录不在长期保留保证内。
- 开启模型自动整理会使用你配置的文本服务，可能产生费用；界面会先征求同意。有冲突或不确定的内容才集中请你核对。
