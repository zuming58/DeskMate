# DeskMate 桌面与 EasyInput 人工验收

## 构建产物

- 应用：`release/win-unpacked/DeskMate.exe`
- 自包含输入桥：打包后位于 `resources/input-bridge/DeskMate.InputBridge.exe`
- 输入桥只读监听 Raw Input，不需要用户安装 .NET 运行库。

## 自动化结果

- `npm test`：覆盖 F22 按下/释放、防抖、重复事件、无按下的释放、断线复位、右 Alt 开关、Escape 取消、快捷键捕获、辅助进程重启、状态机、历史优先、剪贴板回退、Maker 配置 codec 和 Host Action。
- `npm run build`：Web 构建和 Sites 产物。
- `npm run build:desktop`：自包含输入桥和 Windows Electron 包。
- 打包版烟测：模拟语音切换后生成历史与剪贴板文字，退出码 0。
- 2026-08-25 本轮自动化：68/68 通过；ESP-IDF Host CTest 3/3；桌面打包与打包版烟测通过。
- 真机状态必须以本次界面显示为准；历史枚举成功不能代替当前连接证据。

## 本轮建议测试顺序

先测不依赖板子的 1～4，再连接 EasyInput 测 5～7。每项只判断“符合/不符合”，不符合时截图并注明当前页面、触发方式和实际结果。

### 1. EasyInput 原生语音键与普通键盘隔离

1. 在“设置 → 输入与快捷键”确认“普通键盘全局快捷键”默认关闭。
2. 在普通电脑键盘按 `Ctrl+Shift+Space`、`Ctrl+Shift+E` 和 F22，确认均不会弹出录音胶囊。
3. 按 EasyInput KEY1，确认只启动一次文字语音输入；按 KEY3，确认只启动一次语音编辑。
4. 连续空闲观察 5 分钟，确认没有无按键的自动录音。

### 2. 备用语音快捷键（显式开启后）

1. 在“设置 → 输入与快捷键”显式开启“普通键盘全局快捷键”，再点击备用语音快捷键区域。
2. 按一个包含 `Ctrl`、`Alt`、`Shift` 或 `Win` 的组合，例如 `Ctrl+Alt+V`；不应需要手工输入字母。
3. 确认候选组合显示正确，点“确认并保存”。
4. 保持在任意非语音页面，按新组合开始录音，再按一次结束；页面不应跳转。
5. 再试一个只有字母的按键：软件应拒绝，避免覆盖正常输入。
6. 测完恢复为 `Ctrl+Shift+Space`，或保留你最终想用的组合。

### 3. 语音输入到 Codex

1. 在 DeskMate 设置中确认“输出到当前输入框”已开启，千问 ASR 状态正常。
2. 点击 Codex 对话框，使光标留在对话框内。
3. 默认用实体语音键开始；只有上一项明确打开普通全局快捷键后，才可用全局快捷键。只应出现底部居中胶囊，DeskMate 主窗口不得抢焦点或跳到语音页。
4. 说“这是一次 DeskMate 语音输入测试”，再次触发结束。
5. 预期：胶囊依次显示录音、识别/整理、输出、完成；文字进入原 Codex 输入框。
6. 若原窗口失焦，预期应自动降级到剪贴板，并在历史中保留文本；不要重复说一遍覆盖证据。
7. 转写阶段不得把静止的麦克风电平伪装成 `0%` 进度；应显示“处理中”。请求失败时胶囊必须进入失败终态，历史明确标记“转写请求失败”，下一次触发仍可重新开始。

### 4. 麦克风来源选择

1. 首次启动确认来源为“电脑麦克风”，并能继续选择具体 Windows 输入设备。
2. 切到 EasyInput，重启 DeskMate，确认选择仍保留。
3. EasyInput 音频就绪时开始录音，确认界面显示“本次已锁定”，录音中两个来源选择框均不可操作。
4. 开始前关闭或断开 EasyInput 音频，确认明确提示板载音频不可用，并说明本次回退到电脑麦克风；不得显示板载正在收音。
5. 板载录音开始后再断开网络或板子，确认当前录音安全结束并报错，不得切到电脑麦克风继续收音。
6. 蓝牙麦克风显示“待接入”且不可选择。

### 5. 历史复制

1. 先复制一段容易辨认的旧内容作为对照。
2. 在“历史记录”对另一条记录点“复制”。
3. 到记事本或 Codex 粘贴，必须得到刚选中的历史内容，而不是旧剪贴板。
4. 若系统拒绝剪贴板写入，界面必须显示失败，不能显示“已复制”。

### 6. 本机按键、旋钮和打开应用配置

1. 逐个选择 KEY1～KEY8，确认动作修改后切换页面再返回仍被保留。
2. 选择“快捷键”时用录制器输入组合；选择“固定文字”时填写文字。
3. 选择“打开应用”，搜索一个已安装应用；确认列表中没有裸路径，选择后显示应用名。
4. 点“测试打开”，确认启动的是所选应用；再用“选择其他应用”测试一个明确的 `.exe` 或 `.lnk`。
5. 点击旋钮，分别测试滚动页面/移动光标、上下/左右、速度 1～5、反向开关和短按动作；离开再返回应保留。
6. 本阶段这些修改应标为本机已保存，不得自动声称板上已经生效。

### 7. EasyInput 连接与基础键

1. 连接 EasyInput，打开“设备与连接”。
2. 确认“EasyInput HID”为已连接、“Windows 输入桥”为运行中。
3. 在记事本验证回车、退格、全选、复制、粘贴、撤销仍由 Windows 正常执行。
4. 开启按键诊断后只应看到允许的键名/动作/时间，不应记录输入文字或完整设备路径。

### 8. 实体语音闭环

1. 保持 Codex 或记事本输入框焦点，按一次实体语音键开始、再按一次结束。
2. 当前公开 Maker 默认是 `Ctrl+Shift+Space`，F22 仅为兼容入口；两者最终以真机观察为准。
3. 连续完成 10 次，确认不重复触发、主页面不跳转、胶囊不抢焦点、历史不丢失。
4. 录音时拔掉板子或麦克风，确认会话安全结束且软件不崩溃。

### 9. 同步到键盘的安全预期

1. 当前可以点击“同步到键盘”验证提示。
2. 预期：软件提示必须先读取并合并板上网络、音频和按键配置，并阻止覆盖写入。
3. 不应显示“同步成功”，也不应改变板上的现有配置。
4. 在后续实现完整读取/合并链路并另行确认前，不使用其他工具向厂商 HID 写配置。

## 旧版语音闭环摘要

1. 连接 EasyInput 板子，打开 DeskMate 的“设备与连接”。
2. 确认“EasyInput HID”为“已连接”，“Windows 输入桥”为“运行中”。
3. 打开记事本或 Codex 输入框，保持输入焦点，不要点回 DeskMate。
4. 按一次板子语音键（当前真机已确认为 `Ctrl+Shift+Space`；F22 为兼容路径）：悬浮窗应显示“正在录音”，且不抢焦点。
5. 说一句话，再按一次语音键：状态依次进入转写、输出、完成。
6. 确认历史新增，文字进入原输入框；若焦点变化，确认文字已在剪贴板。
7. 连续完成 10 次，确认无重复触发、无残留 F22 状态、历史不丢失。
8. 录音时拔掉板子或麦克风，确认当前会话安全结束且软件不崩溃。
9. 验证板子的回车、退格、全选、复制、粘贴、撤销仍由 Windows 正常执行。

## 若语音键不是 F22

当前资料与历史故障报告指向 F22，但物理按压仍是最终证据。如果设备显示已连接而语音键无触发，开启“按键诊断”，记录不含文字的键名/动作/时间，并补充厂商按键组合资料；不要向 `COL03` 自定义 HID 接口发送猜测数据。
