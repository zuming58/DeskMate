# DeskMate 当前产品人工验收清单

基线：T31 `t31-ui-data-safety` 审计修复包，保留 T30 的语音修复。参见 [修复结果](../reviews/t31-audit-fixes-2026-09-12.md) 和 [原审计报告](../reviews/product-function-audit-2026-09-12.md)。每次记录实际 build、日期和逐项结果，不用历史版本通过代签新版本。

本清单是待执行方案，不代表本轮已测试。任何硬件测试需用户在场；不授权烧录/Flash/NVS 读取或任意设备写入。现有按键“同步”需先预览精确修改并确认。录音/原文/密钥不附在诊断包。

## 先决条件

- [ ] 确认使用 T31 或后续修复包；配置导入/重置保留历史已通过隔离数据测试，人工验收仍先用独立测试数据，不删除日常记录。
- [ ] 删除、保留策略、导入冲突、断网故障测试使用独立临时数据；不删除 KnowledgeOS 已封存 Raw。
- [ ] 保存当前配置/提示词备份；明确普通配置备份不包含完整记忆、录音、应用白名单及凭据，不能当全量恢复包。
- [ ] 记录本次版本号/build；中途不要更新或重启软件来混淆故障来源。

## 1. 工作台和通用导航

- [ ] 九项主导航均能到正确页面；返回、收起/展开侧栏不丢未保存草稿。
- [ ] 工作台刷新和各卡片跳转正确；无数据为空态，读取失败有提示，不显示假成功。
- [ ] 窗口 1440×1024、960×680、系统缩放下主要按钮可见、可滚到；无整页横向溢出。
- [ ] 托盘收起、恢复、退出区别清楚；没有活动录音时关闭前台不等于应用崩溃。

## 2. 语音输入（第一优先级）

- [ ] Codex 输入框和浏览器 textarea 各录短句/长句 5 次：按键停止后仅插入一次，尾句不丢，无自动发送。
- [ ] 分别测原样、智能、自定义：实际输出符合模式；智能失败能保留原文，提示不谎称整理成功。
- [ ] 处理中 Esc 不残留录音/输入；下一次立即可正常录入。
- [ ] 录音后切到另一个窗口：不向错误窗口输入，说明回退原因，可从剪贴板/历史找回。
- [ ] 关闭自动插入后分别测仅历史和复制；不意外向当前应用打字。
- [ ] 悬浮条不抢焦点、不频繁闪动；显示设置关闭后不再出现。
- [ ] 语音编辑在显式映射后对选中文字生效；无选择时明确拒绝，不误触 AI 陪伴。

## 3. AI 陪伴

- [ ] 连续聊天至少 15 轮，涵盖长句、半句停顿、回答刚结束立即说、空闲约 9 秒再说。
- [ ] 手动打断与自然插话分别测；无旧回复尾音重复、无听到了却静默退出。
- [ ] 识别/模型失败能说明并恢复；真正静音到设定时长正常结束，重新唤醒可用。
- [ ] 保存用户资料、人设、音量、唤醒短语、静音/空闲时间，重启后仍保存，生效时机清楚。
- [ ] 同日重开能接续；次日普通问候不续讲昨天笑话。不要为此修改真实系统时钟，等自然跨天或用隔离时钟测试。
- [ ] 主动问“昨天做了哪些工作”可引用陪伴和语音输入两类有日期的记录；不把听写中的他人内容当本人事实。
- [ ] 普通闲聊不强制调用 KnowledgeOS；显式历史/知识问题可按策略检索并对失败诚实说明。

## 4. 历史与词库（审计修复后）

- [ ] 历史搜索、展开原文、复制结果、复制原文、试听、导出均产生真实结果。
- [ ] 删除临时一条/清空临时历史时核对文字和录音；部分失败不得报告全部成功。
- [ ] 词库左侧原词能连续输入和中文选词，不每敲一字失焦；新增、删除、替换规则重启仍在。
- [ ] 临时词库导出再导入一致；非法文件/重复项/取消导入不破坏现有词库。
- [ ] 实际听写验证一个专名热词和一个确定性替换规则，不仅看页面数量。

## 5. 提示词与场景按键

- [ ] 新建/编辑/另存/收藏/搜索/最近/回收站恢复；上下排序重启仍保持。过滤状态不能误改全局顺序。
- [ ] 提示词正文可完整阅读，列表只在固定框内滚动；鼠标向上和实体旋钮右转向下分别符合设置。
- [ ] 提示词页及按键页 Tab/Shift+Tab 仅切场景；输入框、录制快捷键、弹窗内正常编辑。
- [ ] 第 4 键调出、选中、再按复制收起，焦点返回工作页；第 8 键只粘贴，不自动发送。
- [ ] Esc 取消临时页不复制；手动浏览时不误藏主窗口；语音取消不被提示词页抢走。
- [ ] 1/2/3/4/8 共用修改跨场景一致；5/6/7 修改只影响当前场景。
- [ ] Ctrl+B 等自定义组合能捕获；常用动作、固定提示词、白名单应用、禁用各测一个。
- [ ] 同步前取消不写板；确认后回读结果与实际实体键一致。场景切换不重复写 NVS。
- [ ] 新建第 4 个以上场景仍可访问；补管理功能后再测改名、排序、迁移/删除的确认和取消。

## 6. 记忆与 KnowledgeOS

- [ ] 小时增量只处理新内容；手动收尾产生综合/work/personal 日期稿，完整回顾原文而非只拼小时摘要。
- [ ] 提前收尾后新记录归下一工作日；自然发生日期仍正确，重复点击不连续关闭多天。
- [ ] work/personal 两份独立回执；personal 项目为空，有来源，推测仍待确认。连接测试成功不替代本项。
- [ ] 中枢暂不可用时待同步可见；恢复后重试不重复提交；两类中一类失败不冒充整天成功。
- [ ] 策略编辑停留 40 秒、搜索或切过滤后草稿不丢；保存失败草稿保留，重启后是已保存值。
- [ ] 候选纠正/保留/忽略、检索、导出和删除的结果一致；删除后不能从旧上下文继续引用。
- [ ] 隔离数据验证 20 天清理门、同步未成功时不删、受管投影冲突不覆盖用户文件；单独核对语音历史和录音保留范围。

## 7. 设备、Codex 和小智（用户在场）

- [ ] 电脑麦克风、已配置板麦分别采集；板麦开始前失败可明确回退，录音中断线不得静默换源。
- [ ] 新的真实 Codex 任务自动出现，项目名不播哈希；等待/完成播报不重复，关播报仍能看状态。
- [ ] EasyInput 七种工作灯状态与说明相符；输入反馈结束恢复状态底色，空闲熄灭。
- [ ] 关闭小智时动作被拒绝，软件陪伴/听写/按键/记忆仍可用；重启保持选择，重新开启不回放旧动作。
- [ ] 已验收边界内点头、关注、寻找、激活的舞蹈及配乐；停止/回中/急停与恢复保持有效。不要更改校准/机械边界。
- [ ] 诊断能导出实际故障类别，不包含 API Key、音频、识别正文、设备/网络身份。

## 8. 分享前交付验收

- [ ] 修复后配置导入/默认恢复保留历史，错误文件不修改原配置；异常保存有可见反馈。
- [ ] 测当前安装包的首次安装、升级、托盘退出、重启、卸载/保留数据；不要以 unpacked 目录包启动成功替代。
- [ ] 仅 EasyInput 的另一台电脑可启动核心功能；缺少可选小智/KnowledgeOS 时不伪装健康，不阻止普通办公。
- [ ] 归档精确代码版本、包哈希、验证与人工结果；检查无用户原文、录音、密钥进入发布或 Git。

记录模板：`条目编号 | 版本 | 通过/失败/跳过 | 预期与实际差异 | 脱敏诊断时间`。未实测一律保留空框，不根据单测结果代勾。
