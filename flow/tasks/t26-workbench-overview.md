# T26 — Comprehensive workbench

## User story

用户远程使用 DeskMate，暂时不能操作硬件。希望打开首页就能看到整体软件、连接、使用和记忆情况，而不是只有一个巨大的桌宠表情。

## Scope

- 沿用当前产品风格，缩小陪伴标识；首页改为使用指标、连接、记忆进度、工作场景、项目状态和快捷入口。
- 从现有主进程 store 和 SQLite 生成只读投影，不新建统计数据库，不使用模拟历史冒充真实数据。
- 相伴天数、听写/发言计数、长期记忆、同步状态均有明确口径。
- 完整/空库/断开/读取失败都可用，1440×1024 与 960×680 不横向溢出。
- 软件回归、真实生产 UI 的隔离 Electron 检查和 Windows 打包。

## Exclusions

无烧录、按键同步、音频/舵机试验或远端知识写入；不改记忆保留策略、调度时间、AI 配置和用户数据。不扩展音乐或传感器。
