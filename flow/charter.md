# Project charter

## Mission

构建一个 Windows 桌面 AI 工作伙伴：先把 EasyInput 键盘语音输入做成稳定、可诊断、可迁移的日常工具，再把 AI 工作状态映射为桌宠表情、动作、屏幕和未来硬件反馈。

## Users

- 希望用实体按键快速语音输入、但不愿操作命令行的普通用户。
- 同时使用 Codex、Claude Code、Hermes 或 Workbody 的开发者和创作者。
- 需要可解释设备状态、历史记录和隐私控制的硬件学习者。

## Success criteria

- EasyInput 语音键可稳定完成录音、转写、整理、历史和目标窗口输出。
- 断网、拒绝权限、拔出设备、识别失败时不崩溃且不丢原始内容。
- 板载麦克风与厂商 HID 按公开固件合同接入，不依赖猜测或局域网扫描。
- AI 状态只有在真实适配器接入后才驱动真实硬件。
- 任意一台电脑从 GitHub 克隆后，能只靠本仓库文档继续开发。

## Boundaries

- 本仓库不保存课程资料、外部仓库完整副本、API Key、用户录音或历史正文。
- 固件是独立上游，本仓库先实现 companion；烧录必须单独授权。
- 不承诺跨平台桌面支持，当前以 Windows 为正式目标。
