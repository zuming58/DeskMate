# Project charter

## Mission

构建一个完整的 DeskMate 软硬件 AI 工作伙伴：Windows 软件负责体验、状态、电脑扬声器输出和编排；EasyInput ESP32-S3 运行 DeskMate 总控固件，负责实体输入、已验收的麦克风采集和板间协调；小智 ESP32-S3 运行 DeskMate 云台固件，负责表情、屏幕和双舵机安全执行。两块板的扬声器下行和其他硬件扩展不再属于当前产品范围。

## Users

- 希望用实体按键快速语音输入、但不愿操作命令行的普通用户。
- 使用 Codex 的开发者和创作者。
- 需要可解释设备状态、历史记录和隐私控制的硬件学习者。

## Success criteria

- EasyInput 语音键可稳定完成录音、转写、整理、历史和目标窗口输出。
- 断网、拒绝权限、拔出设备、识别失败时不崩溃且不丢原始内容。
- 板载麦克风与厂商 HID 按公开固件合同接入，不依赖猜测或局域网扫描。
- EasyInput 总控固件与小智云台固件均可从本仓库复现构建，并保留各自硬件安全、来源和许可证证据。
- EasyInput 总控与小智执行节点通过版本化 DeskMate Link 交换能力、命令、状态、完成和错误；断线、重复、超时和急停行为可验证。
- 伴侣对话与语音输入可在 Windows 本地维护可查看、纠正、导出和删除的长期记忆；不做人物、声纹或说话人识别。
- AI 状态只有在真实适配器接入后才驱动真实硬件。
- 任意一台电脑从 GitHub 克隆后，能只靠本仓库文档继续开发。

## Boundaries

- 本仓库不保存课程资料、外部参考工程完整副本、API Key、用户录音或历史正文。
- 最终新固件属于本产品仓；外部 Maker 和小智目录只提供参考证据，按选择的功能和许可证做有来源记录的重写、移植或派生。
- 固件开发授权不等于设备写入授权；烧录、读取 Flash、备份/改写分区与 NVS、写 eFuse 和舵机动作均需按风险单独确认。
- 首版板间链路已选择 3.3 V TTL UART，但选择方案不等于允许接线或烧录；电平、独立供电、共地、日志迁移、framing 和恢复性验收必须先通过。
- 人物档案、长期记忆和声纹属于 Windows 本地敏感数据，不写入固件；儿童资料由监护人管理，默认不长期保存原始登记录音。
- 不承诺跨平台桌面支持，当前以 Windows 为正式目标。
